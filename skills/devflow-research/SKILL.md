# DevFlow Research

Answer a focused research question before planning or implementation.

Before working, read `../_shared/references/devflow-conventions.md` when available.

## Process

1. State the research question.
2. Inspect relevant code or sources.
3. Capture findings, constraints, and confidence.
4. Create `research.md` from `references/templates/research.template.md` when persistent output is useful.
