# DevFlow Commit

Prepare a clean commit after verification.

Before working, read `../_shared/references/devflow-conventions.md` when available.

## Process

1. Inspect changed files.
2. Confirm verification evidence exists.
3. Summarize changes and risks.
4. Create or update `commit_summary.md` from `references/templates/commit_summary.template.md`.
5. Suggest a concise imperative commit message.
