# DevFlow Insight

Extract reusable learning from work.

Before working, read `../_shared/references/devflow-conventions.md` when available.

## Process

1. Read task artifacts, verification, and failures.
2. Identify reusable lessons and gotchas.
3. Create `insight.md` from `references/templates/insight.template.md`.
