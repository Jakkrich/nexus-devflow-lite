# DevFlow PRD

Create a product requirements document for larger initiatives.

Before working, read `../_shared/references/devflow-conventions.md` when available.

## Process

1. Clarify product problem and target users.
2. Define goals, non-goals, requirements, and success metrics.
3. Capture risks, dependencies, rollout, and open questions.
4. Create `prd.md` from `references/templates/prd.template.md`.
