# DevFlow Changelog

Draft a human-readable changelog entry.

Before working, read `../_shared/references/devflow-conventions.md` when available.

## Process

1. Read task artifacts or changed files.
2. Summarize user-visible changes, fixes, and risks.
3. Create `changelog_entry.md` from `references/templates/changelog_entry.template.md`.
